## Boundaries

**Sandbox only: no real payment, inventory reservation, manufacturing, or shipping.** OAuth links a browser guest workspace, not a verified customer account. No email/password account is used in this recording.

This does not establish independent second-account linking, physical-mobile rendering, or public directory approval. The personal plugin is not the unpublished directory draft. The actual Platform publisher connection is shown separately. Initial card loading needed **Try again**, which is visible in the video. The negative prompts demonstrate model behavior; they are not a filmed adversarial server-isolation test. No repeated confirmation-token replay is filmed.

Screenshots exclude browser address bars and unrelated chat history. Authentication tokens, consent callback codes, cookies, passwords, and identity-verification documents are not included. The visible draft and receipt are deliberately created sample data.

The final MP4 was fully decoded without errors; video/audio streams and non-silent narration were checked. Representative frames from every chapter were visually inspected. The narration is documented rather than represented as an independently transcribed recording.
